# Data resources

Bactrian-X (`MBZUAI/Bactrian-X`) is downloaded automatically via `huggingface_hub`
on first run and cached here.

Structural-trigger resources (place here; build/obtain separately):
- `swahili_vitenzi_v1.csv`        — Swahili verb conjugations (-ngali- counterfactual).
  Source: Mathayo & Kondoro, NLPIR'24; Mendeley Data 10.17632/rvt89578g5.2 (CC BY 4.0).
- `pashto_res/pashto_ergative_forms.json` — Pashto ergative perfective-past forms.
  Source: LingDocs pashto-inflector (MIT OR Apache-2.0).
- `mn_res/mn_ablative_forms.json` — Mongolian ablative noun-case forms.
  Source: UniMorph 4.0 `khk` (Batsuren et al., LREC'22).
